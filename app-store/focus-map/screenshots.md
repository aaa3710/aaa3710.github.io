# スクリーンショット構成

AppleはiPhone用に1～10枚を受け付け、PNG/JPEG、アルファなしを求める。1320×2868pxは6.9インチ表示向けの受理サイズの一つ。現行素材はこの寸法と色条件を満たしている。

## 日本語・英語の共通順序

1. `01-focus-map.png` — 被写界深度と連続的なボケ量
   - 最初の一枚。ユーザーが得る答えを最短で示せる。
   - 現行候補を維持。
2. `02-apex.png` — APEXの4行と値の調整
   - 2026-08-27の再設計後の現行画面で日英とも撮り直す。
   - 撮り直すまで提出不可。サイトにも旧画面を掲載しない。
3. `03-actual-size-sensors.png` — センサー形式の同縮尺・実寸比較
   - 現行候補を維持。
   - 実寸表示の最終主張は、物理カード／定規との実機確認後に確定する。
4. `04-bellows.png` — 蛇腹伸長の露出補正
   - 現行候補を維持。入力値と結果が読み取れることを再確認する。

## 撮り直し時のルール

- 日本語と英語で同じ操作状態・同じ並びにする。
- 実際のアプリ画面だけを使い、存在しない機能や合成UIを入れない。
- 1枚目は機能一覧ではなく、Focus Mapの固有価値である「範囲と連続曲線」を見せる。
- ステータスバー、戻る表示、言語、数値、単位を最終ビルドと照合する。
- 寸法、RGB、sRGB、アルファなしを再検査する。
