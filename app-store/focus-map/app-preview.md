# App Preview撮影計画

## 方針

App Previewは必須ではない。まず4枚の静止画を正確に完成させ、実機または最終候補ビルドの現行画面を安定して録画できる場合だけ追加する。AI生成UIや古いAPEX画面を完成版動画へ混ぜない。

## 27秒・縦向き・無音でも成立する台本

| 時間    | 実画面で行うこと                                 | 伝える内容                 |
| ------- | ------------------------------------------------ | -------------------------- |
| 0–3秒   | Focus画面を静止。2m・F8、許容範囲0.97m–∞を見せる | 答えが先に読める           |
| 3–8秒   | F値を1段変え、範囲と曲線の変化を見せる           | 絞りの違いを連続量で確認   |
| 8–13秒  | F値比較または距離比較へ切り替える                | 複数条件を同じ軸で比較     |
| 13–17秒 | センサー比較を開き、形式を一度変更する           | 数字だけでなく大きさで理解 |
| 17–23秒 | 現行APEX画面で値を3分の1段調整する               | 4値の関係を崩さず計算      |
| 23–27秒 | 蛇腹伸長画面で入力と結果を見せる                 | 大判・接写の補正にも対応   |

## 制作条件

- 日本語版と英語版を別々に録画する。
- 5秒付近が静止画としても意味を持つ構図にし、ポスターフレーム候補にする。
- タップ表示や字幕を加える場合も、アプリの操作を隠さない。
- 15～30秒、500MB以下、最大30fps。H.264なら`.mov`、`.m4v`、`.mp4`を使用できる。
- 6.9インチiPhone向け縦動画の受理解像度は886×1920px。提出直前にAppleの現行仕様を再確認する。

参考: https://developer.apple.com/help/app-store-connect/reference/app-information/app-preview-specifications/
