# Focus Map — 日本語メタデータ

- 名前: `Focus Map`
- サブタイトル: `ピントの範囲をすばやく確認`
- プロモーション用テキスト: `ピント位置と絞りから、手前から奥までどこが合って見えるかを確認。撮影前の計算を短くして、写真に集中できます。`
- キーワード: `被写界深度,ピント,焦点距離,錯乱円,絞り,露出,APEX,センサー,カメラ`

## 説明

撮影前に、どこまでピントが合って見えるかを手早く確認。

Focus Mapは、ピントを置く距離と絞りから、合って見える範囲を確かめるiPhoneアプリです。マニュアルフォーカスのカメラやレンズで、撮影前の計算を手早く済ませたいときに使えます。

【欲しい答えを先に】
手前と奥の境界を大きく表示します。この範囲は「被写界深度」と呼ばれます。範囲の外でぼけがどのように増えるかも曲線で確認でき、絞りやピント位置を変えた場合を比べられます。

【新しい機材の距離感をつかむ】
まだ感覚が身についていないカメラやレンズでも、計算結果を目安にしながら撮影できます。使う機材とよく使う距離はiPhone内に保存できます。

【大きさを図で比べる】
スマートフォンから中判まで、代表的なセンサーの大きさを同じ縮尺で比較できます。対応端末では実寸表示も利用でき、幅、高さ、対角線、面積の違いも確認できます。

【仕組みまで楽しみたい人へ】
絞り、シャッター速度、ISOと、APEXによる露出の関係を確認できます。大判カメラや接写で必要になる、蛇腹の長さによる露出補正も別画面で計算できます。

【データはiPhone内に】
アカウント、広告、利用状況の解析、追跡はありません。計算値と設定を自動で外部へ送りません。日本語と英語をアプリ内で切り替えられます。

計算結果は撮影前の目安です。実際の写りは、レンズの特性、回折、ぶれ、被写体の動き、画像処理などでも変わります。
