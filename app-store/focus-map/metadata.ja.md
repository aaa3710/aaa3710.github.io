# Focus Map — 日本語メタデータ

- 名前: `Focus Map`
- サブタイトル: `ピントと露出を見える化`
- プロモーション用テキスト: `被写界深度、連続的なボケ量、センサー実寸、APEX露出を、撮影中にすばやく確かめられます。`
- キーワード: `被写界深度,ピント,焦点距離,錯乱円,絞り,露出,APEX,センサー,カメラ`

## 説明

Focus Mapは、撮影前の判断を減らすためのピント・露出計算ツールです。

ピントモードでは、機材、ピント位置、F値、許容錯乱円から近点・遠点を計算し、被写体距離に応じてボケがどう増えるかを曲線で確認できます。数値は端末内に保存でき、実焦点距離、35mm判換算、カスタム撮像面、大判フィルムの実効画面にも対応します。

センサーガイドでは、中判44×33までの代表形式を同じ縮尺または実寸大で比較できます。選んだ形式の幅・高さ・対角長・面積をそれぞれ1として、ほかの形式との比も確認できます。

露出モードでは、APEXのAv・Tv・Bv・Svを固定した4行で示し、選んだ1値を残り3値からその場で計算します。F値・シャッター・ISOと対応するAPEX値を常に並べ、中央復帰型スライダーで3分の1段ずつ調整できます。Bvは場面の明るさと結び付けて確認できます。大判・接写向けには、焦点距離と蛇腹伸長から露出倍率、補正段数、実効F値を求める別画面があります。

アカウント、広告、解析、追跡、外部通信はありません。日本語と英語をアプリ内で切り替えられます。

計算は薄レンズ近似とAPEXの代数関係に基づく補助です。実際のレンズ、カメラ、測光、撮影結果との差を保証するものではありません。
