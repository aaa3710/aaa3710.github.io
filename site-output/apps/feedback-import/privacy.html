Minato Feedback Local Import

Minato Feedback Local Import のプライバシー

専用フィードバックの回答取得、利用目的、保存と共有、アクセスの取り消しについて説明します。

運営者と対象

開発者 Minato が管理する本人専用ツール「Minato Feedback Local Import」に適用します。アプリ本体のデータの扱いは、各アプリのプライバシー説明をご確認ください。

アクセスする情報と目的

Google Forms APIの回答読み取り権限（forms.responses.readonly）を使い、登録済みの専用フォームから回答本文、送信日時、回答と質問を対応付ける識別情報を取得します。不具合や要望の把握、安全な改善候補の整理、重複処理の防止のために使用します。このツールはフォームの編集や回答の削除を行いません。

取得範囲

専用フォームでは氏名やメールアドレスを回答項目として要求せず、メールアドレスを自動収集しません。共通Contactの本文や任意の返信先、Gmailのメール、Google Contactsの連絡先は、このツールの取得対象ではありません。自由記述に本人が識別情報を記入した場合まで匿名性を保証するものではありません。

保存と安全管理

回答原文はアクセスを制限したGoogleフォームに保存されます。取込時には開発者のMac内で回答を処理し、原文を通常のログや開発記録へ複製しません。Macには、処理状況、重複を識別するための値、本文を含まない改善候補、および認証に必要な情報を、所有者だけが利用する保存先で管理します。認証情報は公開サイトやGitへ保存しません。

共有とAIの利用

この取込処理から回答原文を外部AIへ送信しません。開発支援に使う候補は、自由記述を含まない、あらかじめ定めた分類や操作の項目だけに制限します。広告、販売、信用評価や汎用AIモデルの学習には利用しません。通常受付と実回答の整理はまだ開始していません。処理方法を変更する場合は、開始前に説明を更新し、必要な同意を得ます。

保持・削除・認証の取り消し

回答は目的に必要な間だけ保持し、不要になれば削除します。周期だけを理由に一律削除しません。開発者はGoogleアカウントの接続管理から、このツールへのアクセスを取り消せます。取り消しは新たな取得を止めるもので、すでにGoogleやMacに保存された記録を自動削除する操作ではありません。

問い合わせと請求

プライバシーの質問や削除等の請求は共通のお問い合わせで扱い、受付状況も同ページで案内します。TestFlight参加者は、TestFlightに表示される開発者の連絡先も利用できます。匿名の回答は確実に特定できない場合がありますが、法令上の権利を制限するものではなく、適用法令に従って対応します。

Googleのサービスと利用制限

Google APIから受け取った情報の利用と他のアプリへの移転には、Limited Useの要件を含むGoogle API Services User Data Policyを適用します。Google自身のサービスにおける処理はGoogleのプライバシーポリシーに従います。Googleで米国を含む世界各地で処理される場合があり、個々の回答の保存国は指定・特定できません。この説明ページの配信にはGitHub Pagesを使用し、閲覧時の情報はGitHubのプライバシー説明も適用されます。
